# Custom Python Agents & Frameworks

If you build autonomous agents using **LangChain**, **CrewAI**, **AutoGen**, or a custom Python loop, you can integrate Dmint directly into your tool definitions.

---

## LangChain Integration

Wrap LangChain's `@tool` functions with `@dmint.protected`:

```python title="langchain_tools.py"
import json
from datetime import timedelta
from langchain_core.tools import tool
from dmint import Dmint, Policy, SQLiteApprovalStore
from dmint.models import TrustedContext
from dmint.errors import AuthorizationError

# Initialize Dmint
store = SQLiteApprovalStore("./approvals.sqlite3", deployment_epoch="prod-v1")
with open("policy.json", "r", encoding="utf-8") as f:
    policy = Policy.from_mapping(json.load(f))

dmint = Dmint(
    policy=policy,
    approval_store=store,
    context=TrustedContext({}),
    agent_id="langchain-agent",
    approval_ttl=timedelta(minutes=15),
)

@tool
@dmint.protected("system.execute_sql")
def execute_sql(query: str) -> str:
    """Execute a raw SQL query against the database."""
    # This code only runs if Dmint evaluates ALLOW or valid approval credential is provided
    return f"Executed SQL: {query}"
```

### Safe LangChain Tool Execution

When an agent invokes a tool that requires human approval:

```python
try:
    result = execute_sql.invoke({"query": "UPDATE accounts SET balance = 0 WHERE id = 1"})
except AuthorizationError as exc:
    # Tool paused fail-closed.
    # The request is now visible in dmint dashboard.
    print(f"Action intercepted: {exc}")
```

## CrewAI Custom Tool Integration

In CrewAI, inherit from `BaseTool` and protect the `_run` method:

```python title="crewai_tools.py"
import json
from datetime import timedelta
from crewai.tools import BaseTool
from dmint import Dmint, Policy, SQLiteApprovalStore, ApprovalRequiredError, AuthorizationError
from dmint.models import TrustedContext

store = SQLiteApprovalStore("./approvals.sqlite3", deployment_epoch="prod-v1")
with open("policy.json", "r", encoding="utf-8") as f:
    policy = Policy.from_mapping(json.load(f))

dmint = Dmint(
    policy=policy,
    approval_store=store,
    context=TrustedContext({}),
    agent_id="crewai-ops-agent",
    approval_ttl=timedelta(minutes=15),
)

@dmint.protected("filesystem.delete")
def execute_file_delete(file_path: str) -> str:
    return f"Successfully deleted {file_path}"

class ProtectedFileDeleteTool(BaseTool):
    name: str = "delete_file"
    description: str = "Deletes a file from the server."

    def _run(self, file_path: str) -> str:
        try:
            return execute_file_delete(file_path)
        except ApprovalRequiredError as exc:
            return f"APPROVAL_REQUIRED: Action paused. Approval ID is {exc.approval_id}."
        except AuthorizationError as exc:
            return f"DENIED: Action forbidden by policy: {exc}"
```

## Polling for Approval in Custom Loops

If your agent runs as a daemon and needs to wait for human approval before resuming:

```python title="agent_poller.py"
import time
from dmint import SQLiteApprovalStore, ApprovalRecord, ApprovalState

def wait_for_human_approval(store: SQLiteApprovalStore, approval_id: str, timeout_sec: int = 300) -> ApprovalRecord:
    start = time.time()
    while time.time() - start < timeout_sec:
        record = store.get(approval_id)
        if record and record.state == ApprovalState.APPROVED:
            return record
        elif record and record.state == ApprovalState.REJECTED:
            raise PermissionError("Human operator rejected the action.")
        time.sleep(2)
    raise TimeoutError("Approval request timed out.")
```
