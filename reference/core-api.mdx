# Python Core API Reference (`dmint`)

This page documents the public API exposed by the `dmint` v1.0.1 Python package.

```python
from dmint import (
    Dmint,
    Policy,
    Rule,
    ToolRequest,
    SQLiteApprovalStore,
    LocalApprovalAuthority,
    ApprovalState,
)
```

---

## `Dmint`

The primary authorization and execution orchestrator.

### Constructor
```python
from datetime import timedelta
from dmint.models import TrustedContext

dmint = Dmint(
    policy: Policy,
    *,
    agent_id: str,
    context: TrustedContext,
    integration_id: str = "local-runtime",
    approval_store: SQLiteApprovalStore | None = None,
    approval_verifier: ApprovalVerifier | None = None,
    policy_provenance: PolicyProvenance | None = None,
    approval_ttl: timedelta | None = None,
)
```

### Methods

#### `@dmint.protected(capability: str)`
Decorator that intercepts a Python function. Halts execution if the capability evaluates to `DENY` or `APPROVAL_REQUIRED`.
```python
@dmint.protected("database.update")
def modify_user(id: int, name: str):
    ...
```

#### `dmint.retry(function: Callable, *args, approval_credential: ApprovalAssertion | bytes, **kwargs) -> Any`
Executes an approved retry for a previously intercepted function using a cryptographic approval assertion. Atomically consumes the approval in the store to enforce single-use replay defense.
```python
result = dmint.retry(
    modify_user,
    42,
    "Alice",
    approval_credential=assertion,
)
```

#### `dmint.authorize(function: Callable, *args, capability: str, resource: ResourceSpec = NO_RESOURCE, **kwargs) -> AuthorizedRequest`
Evaluates and pre-authorizes a callable with its arguments against the policy for the given capability. Returns an `AuthorizedRequest` token if permitted, raises `ApprovalRequiredError` if human approval is required (persisting a pending record to SQLite), or raises `AuthorizationError` if denied.

#### `dmint.execute(authorized: AuthorizedRequest) -> Any`
Executes an `AuthorizedRequest` token produced by `dmint.authorize()`.

## `Policy`

Represents an immutable, validated authorization policy.

### Static Methods
```python
# Parse from Python dictionary (mapping containing {"rules": [...]})
import json
from dmint import Policy

with open("policy.json", "r", encoding="utf-8") as f:
    policy = Policy.from_mapping(json.load(f))
```

### Properties
- `policy.rules`: Tuple of `Rule` objects.
- `policy.digest`: SHA-256 hex string representing the canonical digest of this policy.

## `SQLiteApprovalStore`

The Core-owned SQLite database client managing approval lifecycles.

### Constructor
```python
store = SQLiteApprovalStore(
    database: str | Path,
    *,
    deployment_epoch: str,
    recovery_epoch_file: str | Path | None = None,
)
```

<Note>
`deployment_epoch` participates in Core's rollback and recovery protection, tracking epoch state in a companion `.epoch` file (`<db_path>.epoch`) alongside the SQLite database to prevent rollback attacks.
</Note>

### Public Methods

#### `store.get_pending(approval_id: str) -> ApprovalRecord | None`
Retrieves a pending approval record by its `approval_id`.

#### `store.get_approved(approval_id: str) -> ApprovalRecord | None`
Retrieves an approved approval record by its `approval_id`.

#### `store.get(approval_id: str) -> ApprovalRecord | None`
Retrieves an approval record (in any state) by its `approval_id`.

#### `store.require_pending(approval_id: str) -> ApprovalRecord`
Retrieves a pending approval record, raising an error if not found or not in `PENDING` state.

#### `store.save_approved(record: ApprovalRecord) -> None`
Persists a transitioned `APPROVED` approval record to the store.

#### `store.consume_approved(*, approval_id: str, credential: ApprovalAssertion | bytes, expected_request: ToolRequest, verifier: ApprovalVerifier, now: datetime | None = None) -> ApprovalRecord`
Atomically verifies and transitions an approved record to `CONSUMED`. Core's `dmint.retry()` handles this automatically.

#### `store.invalidate_approved(record: ApprovalRecord, *, reason: str, now: datetime | None = None) -> ApprovalRecord`
Invalidates an approved record if policy provenance changes or conditions no longer hold.

#### `store.cleanup_expired(*, now: datetime | None = None) -> int`
Purges expired pending records from the database and returns the count of removed records.

#### `store.close() -> None`
Closes the underlying SQLite database connection cleanly.

## Error Codes & Exceptions

All authorization exceptions derive from `dmint.errors.AuthorizationError`:

| Error Constant | Meaning |
|---|---|
| `DMT_POLICY_DENIED` | Action explicitly forbidden by policy rule or fail-closed default. |
| `DMT_APPROVAL_REQUIRED` | Action is paused awaiting human approval. |
| `DMT_APPROVAL_CONSUMED` | Attempted to replay an assertion that has already been executed. |
| `DMT_APPROVAL_EXPIRED` | Assertion timestamp exceeded time-to-live. |
| `DMT_REQUEST_MISMATCH` | Runtime arguments do not match the approved request fingerprint. |
| `DMT_APPROVAL_POLICY_INVALID` | The policy file was modified after the approval was granted. |
